# Checkpoint and synthesize

1. Save working text and a next action while the task is in flight. Include the evidence read, current blocker, and a path another checkout can open. Use the task CLI so the record and board update together.
2. Put the durable project conclusion in its synthesis. Name the decision, why it holds, who owns the source, and where to verify it. Point to the original source with a path or authorized URL. Read a live source before using it as current evidence. Record its observation time.
3. Put reusable agent craft, skills, routines, and retrieval links in the agent snapshot. Use the stable snapshot path in your registration. Record anything the harness cannot export as a gap. Keep secrets and changing task status out of snapshots.
4. On restart, read main, the task row, and the saved checkpoint. Use recall to find written decisions or methods. Check the exact source before acting.

Use the source map format in ADAPT.md when you create a project.
